# Folders

Folders for every group of the sidebar, so a project stays tidy past a few dozen Actor types, Scenes, or sprites. Folders are plain
files where the format allows it, so the project stays readable in IntelliJ and git (`../CLAUDE.md` → Principles 1). Each addition
lands with its command and AI tool.

- Expanded folders remembered per project in `.kubriko/local`, and moving a whole folder into another by dragging.
